# BedGangChunks 1.1.0 — Paper 26.2

Downloads: [Plugin JAR](dist/BedGangChunks-1.1.0.jar) · [Skin resource pack](dist/BedGangSkin-26.2.zip). On GitHub, open the file and choose **Download raw file**.

## Install

1. Stop your Paper 26.2 server (Java 25).
2. Put `BedGangChunks-1.1.0.jar` in its `plugins` folder.
3. Start the server. No other plugin is required.
4. To see the attached skin, install `BedGangSkin-26.2.zip` in each client's resourcepacks folder and enable it under Options > Resource Packs. Do not extract the ZIP.

For automatic distribution to everyone, host the skin ZIP at a direct HTTPS download URL and set `resource-pack` to that URL in server.properties. Set `resource-pack-sha1` to the hash in `SHA256SUMS-and-skin-SHA1.txt`. Set `require-resource-pack=true` if everyone must accept it. If your server already has a resource pack, merge the ZIP's `assets/bedgang` folder into that pack and recompute its hash. The skin ZIP is not a server plugin; putting it in plugins does not install the skin for clients.

## Commands 

Commands are available without op by default.

| Command | Action |
| --- | --- |
| `/bedgang spawn <radius> [name]` | Create a loader at your feet in your first free slot |
| `/bedgang remove <1-5>` | Remove one of your loaders |
| `/bedgang remove all` | Remove all of your loaders |
| `/bedgang rename 1 &4&lBedgang`| renames your slot 1 bot to dark red, bold Bedgang.|
| `/bedgang rename 2 &aIron Farm`| uses a green name with spaces.|
| `/bedgang spawn 2 &6Gold Farm`| creates a radius-2 loader with a gold name.|
| `/bedgang list`| shows each formatted name beside its slot and location.|

`/bgchunk` is an alias. Each player has a hard limit of five loaders across all worlds, including while offline. Players can remove only their own loaders. OPs have the same five-loader creation limit.

The radius is a **square radius in chunks**, centered on the chunk containing the mannequin. A chunk is 16 by 16 blocks. Radius 0 loads 1 chunk; 1 loads 3x3 = 9; 2 loads 5x5 = 25; 4 loads 9x9 = 81. Radius covers all heights. The default allowed range is 0–4; change `max-radius` in `plugins/BedGangChunks/config.yml` and restart to allow up to 16. Existing loaders retain their saved radii when that setting changes. Larger radii and many players cost server resources. Chunk generation is spread over ticks, but individual new chunks can still cause lag.

Use names without surrounding quotes. Standard codes: &0 through &9, &a through &f for colors; &k obfuscated, &l bold, &m strikethrough, &n underline, &o italic, &r reset. Put color before formatting, as in &4&lBedgang. Names allow up to 48 visible characters and 128 characters including codes. Formatting-only names are rejected. Rename commands affect only your own slots; slot numbers remain the stable way to manage bots. Names save across restarts and entity recreation. Existing records without a name use t4xan BedGang automatically.

## Administrator commands

- `/bedgang admin list` — list every loader and its owner's UUID.
- `/bedgang admin remove <owner-uuid> <1-5|all>` — remove another player's loaders.

These require `bedgang.admin` (OP by default); console can use them too.

## Behavior

The visible entity is a protected, immovable mannequin with display name **t4xan BedGang**. It is not an authenticated player account and does not appear as an online player. The exact supplied PNG is included unmodified, using the classic arm model. Without the resource pack, the custom skin will not render correctly. Set `skin-resource-pack: false` and restart to use Minecraft's default mannequin appearance instead.

Paper plugin chunk tickets keep the selected chunks loaded. Overlapping loaders share tickets; removing one preserves chunks required by others. Loaders persist after logout and server restarts in `plugins/BedGangChunks/loaders.yml`. Do not edit this file while the server is running. Worlds temporarily unavailable retain their records, and resume loading when that world is loaded. Removed mannequin entities are recreated while their loader exists; use the plugin command to remove a loader permanently.

The plugin disables Paper's empty-server pause timer while enabled and restores its prior value when disabled. It does not change server.properties. It cannot keep a shut-down or hosting-provider-suspended server running.

**Chunk loading is not full player simulation.** Natural mob spawning, player-distance-dependent spawners, random-tick crop growth and other mechanics requiring nearby players are not guaranteed by chunk tickets. Paper entity activation settings can also affect unattended entities. This plugin does not emulate these mechanics. Use a real player if a particular farm requires player proximity.
